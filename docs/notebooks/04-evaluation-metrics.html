NB4 · Evaluation metrics

Calibration, cost curves and risk-coverage: the three plots that tell you whether a decision model is shippable.

On this page

File: notebooks/04-evaluation-metrics.ipynb · Runtime: ~1 min CPU · Inputs: saved score files from notebooks 1–3, or the bundled synthetic set.

What gets plotted

  1. Reliability diagram with 15 bins and the ECE annotation, before and after temperature scaling.
  2. Cost curve: expected cost per case as a function of the decision threshold, with the minimum marked and the 0.5-accuracy baseline overlaid.
  3. Risk-coverage curve: error rate on the retained slice versus the fraction of cases auto-decided.
  4. Per-class recall table with support, to catch a class that has collapsed.

Core code

import numpy as np, matplotlib.pyplot as plt
from slm_decision import ece, brier, risk_coverage, expected_cost

# reliability diagram
bins = np.linspace(0, 1, 16)
idx = np.digitize(p, bins) - 1
conf = np.array([p[idx == b].mean() for b in range(15) if (idx == b).any()])
acc  = np.array([y[idx == b].mean() for b in range(15) if (idx == b).any()])
plt.plot([0, 1], [0, 1], "--", color="#999")
plt.plot(conf, acc, "o-", label=f"ECE = {ece(p, y):.3f}")

# risk-coverage
cov, risk = risk_coverage(p, y, preds)
plt.plot(cov, risk); plt.xlabel("coverage"); plt.ylabel("error on covered")

# cost curve
ths = np.linspace(0.01, 0.99, 99)
costs = [expected_cost(spec, (p >= t).astype(int), y) for t in ths]
t_star = ths[int(np.argmin(costs))]

coverage at 5% error         : 0.03

Reading the numbers like an operator

ObservationInterpretationAction
Threshold 0.83 beats 0.50 by 2×Cost asymmetry dominates; accuracy was never the objectivePublish the derived threshold; wire it into the policy
ECE 0.164 → 0.019, T = 3.01Scores were exactly 3× too sharp; ranking unchangedShip temperature scaling; re-fit monthly
Coverage 0.03 at 5% errorThis synthetic task is genuinely hard at 5% riskSet the risk target from the cost matrix, not from ambition
Recall 0.68 / 0.67 against the oracle actionErrors are spread, not concentrated in one classAdd features or labels; thresholding will not fix it
