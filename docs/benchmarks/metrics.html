Performance metrics

Definitions, formulas and thresholds for the metrics that actually decide whether a decision model ships.

On this page

There are dozens of metrics available and about eight that matter. Each one below answers a question a stakeholder will ask, so each one belongs in the release report.

The core eight

Calibration, in practice

import numpy as np

def ece(p, y, n_bins=15):
    bins = np.linspace(0, 1, n_bins + 1)
    idx = np.digitize(p, bins) - 1
    total = 0.0
    for b in range(n_bins):
        m = idx == b
        if m.sum() == 0:
            continue
        total += m.mean() * abs(y[m].mean() - p[m].mean())
    return total

def brier(p, y):
    return float(np.mean((p - y) ** 2))

Reading an ECE: 0.03 is good, 0.05 is acceptable for most business decisions, 0.10 means your thresholds are effectively arbitrary, and above 0.15 the probability output should not be used for cost arithmetic at all.

Risk-coverage: the curve to show a product owner

def risk_coverage(p, y, preds):
    order = np.argsort(-p)                       # most confident first
    cov, risk, errs = [], [], 0
    for i, k in enumerate(order, start=1):
        errs += int(preds[k] != y[k])
        cov.append(i / len(p))
        risk.append(errs / i)
    return np.array(cov), np.array(risk)

This table is the single most useful artefact in a launch review: it converts "how accurate is the model" into "how much can we automate at a risk level we accept".

Cost metrics

cost_per_case   = mean over cases of cost(action_i, y_i)
cost_savings    = (cost_baseline - cost_model) * volume
regret          = mean over cases of (best_possible_cost - realised_cost)
break_even_vol  = build_cost / (cost_baseline - cost_model)   # cases needed to pay back

Report regret alongside cost: it bounds how much better any future model could be on the same cases, which is the number that tells you whether to keep investing.

What not to lead with

Accuracy on an imbalanced set, AUC on a decision you take at a fixed threshold, and average confidence are all seductive and none of them decides a launch. Accuracy hides class collapse; AUC is threshold-free while your product is not; average confidence says nothing about correctness. Keep them in the appendix.
